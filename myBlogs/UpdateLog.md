# yukiBlogs 更新日志

## 2026-08-20

### EdgeOne 部署与访客体验

- 主站支持迁移到腾讯云 EdgeOne Pages 并绑定自定义域名。
- 移除首页天气组件、`/api/weather` 路由和 `QWEATHER_KEY` 示例配置，避免访客反复遇到浏览器定位权限弹窗。
- 控制台部署文案切换为 EdgeOne 源码同步，减少从旧 Vercel 流程迁移后的误导。

## 2026-08-19

### 统计一致性

- 访客初始化、每日去重和累计递增改为 Redis Lua 原子操作。
- 旧版文章阅读键会自动迁移到统一的内容统计键，已有阅读数不再归零。
- 统计接口统一为 `/api/stats/view/[kind]/[slug]`，明确区分文章、杂谈和说说。
- 修复说说快速点击时首次计数请求被初始读取请求吞掉的问题。

### 展示修复

- 无封面的杂谈详情页也会正常记录并显示浏览次数。
- 恢复首页底部状态卡两行网格布局，避免中等屏宽下备案信息被裁切。
- 恢复中文 README，并同步中英文统计规则。

> 站长排除只阻止后续新增记录；启用排除前已经产生的累计数按当前约定保留。

## 2026-08-18

### 访问统计

- 接入 Upstash Redis 保存累计访客与内容阅读次数。
- 累计访客显示在桌面端顶部导航栏（`yukiの宝藏之地` 右侧），单个用户当天访问 +1，排除站长与常见机器人。
- 文章、杂谈、说说卡片封面的右下角展示浏览次数（单个用户当天浏览 +1）；文章/杂谈详情页打开时计数，说说在点开图片或评论时计数。
- 新增 `/stats-owner` 站长浏览器排除页与常见机器人过滤。

### 数据同步与稳定性

- 统一前端运行时配置读取方式。
- 修复友链、个人资料、页脚技术栈、建站时间和 AI 设置保存后仍显示旧数据的问题。
- 修复项目、相册及杂谈数据更新或删除后的残留显示。
- 加强删除结果判定、幂等重试和生成文件原子写入。

### 启动与部署

- Windows `Start.bat` 优先调用 uv 创建的 `.venv\Scripts\python.exe`。
- 补充 Gemini、天气、GitHub OAuth、Upstash Redis 与站长排除所需的服务端环境变量说明。
- 更新技术栈标识为 Next.js 16、React 19 与 Tailwind CSS 4。
